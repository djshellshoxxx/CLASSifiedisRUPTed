## Requirements

- **PS-011-01.R01** An Offer stores listing (with the cid of the verified projection the buyer saw), variant, quantity, buyer, seller, amount as integer minor units, currency, optional note, expiry, status and the cid of the signed offer statement, with tenant and revision per CTR-ID-001.
- **PS-011-01.R02** Offer records are P2 (visible to buyer and seller only), exist only in those two vaults, and are retained under RET-EVIDENCE because accepted offers form commerce evidence; they are purged when the evidence window ends.
- **PS-011-01.R03** The offer amount is immutable after creation; changing the price requires a new offer or a negotiation round.
- **PS-011-01.R04** The vault record classrup.bazaar.offer_record/v1 is distinct from the statements classrup.bazaar.offer/v1 (signer buyer), classrup.bazaar.offer_decision/v1 (signer listing author) and classrup.bazaar.offer_withdrawal/v1 (signer buyer); the acceptance is a classrup.comms.consent/v1 statement signed by the listing author (N13).

| decisionCid? | string — signed decision statement |
| withdrawalCid? | string — signed withdrawal or timeout statement |

| revision | int — CTR-ID-001 ID-4 |
| createdAt | timestamp — RFC 3339 UTC |
| updatedAt | timestamp — RFC 3339 UTC |

**Invariants**
- At most one offer with status made per (buyerId, listingId, variantId) in each vault.
- status accepted implies dealId and consentCid are set and, in the seller vault, an inventory hold was taken at acceptance; later state (completion, cancellation) is the Deal's (F09.S01.M01).
- buyerId differs from sellerId.
- amount, quantity and offerCid never change after creation.
- Field classes are annotated per F10.S02.M02 (all P2; note scanned locally, never federated).

### Storage DDL

```sql
CREATE TABLE bazaar_offer (
  id TEXT PRIMARY KEY, tenant_id TEXT NOT NULL, listing_id TEXT NOT NULL, variant_id TEXT,
  buyer_id TEXT NOT NULL, seller_id TEXT NOT NULL, amount_minor TEXT NOT NULL, currency TEXT NOT NULL,
  status TEXT NOT NULL, expires_at TEXT NOT NULL, revision INTEGER NOT NULL, data TEXT NOT NULL);
CREATE UNIQUE INDEX bazaar_offer_open ON bazaar_offer(tenant_id, buyer_id, listing_id, ifnull(variant_id,''))
  WHERE status = 'made';
CREATE INDEX bazaar_offer_listing ON bazaar_offer(tenant_id, listing_id, status);
```
