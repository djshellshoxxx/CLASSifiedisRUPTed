## Requirements

- **PS-034-01.R01** An AuctionResult stores outcome, winning bid reference, final price, reserve check, ledger head hash, host signature data, deal links, settlement state and second-chance data, with revision per CTR-ID-001.
- **PS-034-01.R02** The result is created once per auction by the host and mirrored read-only in participant vaults; participant-specific fields (deal id, local state) are local.
- **PS-034-01.R03** Result visibility is tiered - public projection shows outcome, final price, winner alias and ledger head; the winner key is disclosed only to the seller and the winner.

## Specification

### AuctionResult

Schema `classrup.auctions.result/v1` · storage **relay+device** · privacy **P2** · retention **RET-EVIDENCE**

| Field | Type and constraints |
|---|---|
| id | uuidv7 — primary key, generated by the host |
| tenantId | uuidv7 — host relay tenant scope |
| auctionId | uuidv7 — ref F04.S01.M01 Auction; unique |
| outcome | enum — won \| unsold |
| unsoldReason? | enum — no_bids \| reserve_not_met |
| winningBidId? | uuidv7 — ref F04.S01.M02 Bid |
| winnerId? | actorId — did:key; visible to seller and winner only |
| winnerAlias? | string — alias of the winner in the ledger |
| finalPrice? | Money — CTR-MNY-001; the winning visible price |
| reserveCheck | enum — none \| met \| not_met |
| ledgerHeadSeq | int — last ledger sequence at close |
| ledgerHeadHash | string — sha256- hash of the last ledger entry |
| closedAtHost | timestamp — host clock, RFC 3339 UTC; evidence of the host clock only |
| hostSignature | string — Ed25519 signature of the host over JCS of the result payload |
| state | enum — determined \| pending_deal \| awaiting_payment \| completed \| non_payment \| second_chance_offered \| failed \| unsold \| voided |
| dealId? | uuidv7 — local ref F09.S01.M01 Deal in this vault |
| secondChance? | object — {candidateId, price: Money, offerCid, expiresAt, status: offered \| accepted \| declined \| expired} |
| nonPaymentReportCid? | string — cid of the signed non-payment report |
| revision | int — CTR-ID-001 ID-4 |

**Invariants**
- At most one AuctionResult per auction.
- outcome won implies winningBidId, winnerId, finalPrice and reserveCheck met or none.
- finalPrice is never lower than the reserve when a reserve exists and outcome is won.
- At most one secondChance per result.

### Storage DDL

```sql
CREATE TABLE auctions_result (
  id TEXT PRIMARY KEY, tenant_id TEXT NOT NULL, auction_id TEXT NOT NULL, outcome TEXT NOT NULL, state TEXT NOT NULL,
  closed_at_host TEXT NOT NULL, revision INTEGER NOT NULL, data TEXT NOT NULL);
CREATE UNIQUE INDEX auctions_result_auction ON auctions_result(tenant_id, auction_id);
CREATE INDEX auctions_result_state ON auctions_result(state, closed_at_host);
```
