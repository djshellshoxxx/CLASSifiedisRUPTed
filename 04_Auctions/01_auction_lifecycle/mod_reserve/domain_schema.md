## Requirements

- **PS-035-01.R01** An Auction stores listing and pinned listing cid, seller, host relay identity and key, currency, start price, reserve commitment, increment table, schedule with acceptBy, soft-close rules version, extension counters, price projection and status, with revision per CTR-ID-001.
- **PS-035-01.R02** The reserve value and its salt are P3 in the seller vault and P2 to the host, the only listed participant - they travel only inside an envelope end-to-end encrypted to hostKeyId (PRV-5) and the host holds them under its published retention - while public terms and events carry only the salted hash commitment and a reserveMet flag.
- **PS-035-01.R03** Money is integer minor units per CTR-MNY-001; increments are computed from a tiered table in major-unit templates converted with ceiling to the currency exponent.
- **PS-035-01.R04** The signed terms pin listingCid (the cid of the published listing projection), acceptBy and softCloseRulesVersion softclose-v1, so the host cannot accept late, the listing text that bids rest on is identifiable, and the soft-close constants cannot change during the auction.

### Auction

Schema `classrup.auctions.auction/v1` · storage **relay+device** · privacy **P2** · retention **RET-EVIDENCE**

| Field | Type and constraints |
|---|---|
| id | uuidv7 — primary key, generated by the seller vault; used as the listing subtypeRef {slug: auctions, entity: Auction, id} |
| tenantId | uuidv7 — host relay tenant scope |
| listingId? | uuidv7 — ref F01.S01.M01 Listing of kind auction whose subtypeRef is this auction; optional in draft, required from schedule on, published at schedule and accept_hosting |
| listingCid? | string — sha256- cid of the published listing projection pinned in the signed terms; required from schedule on |
| listingCidHistory | string[] — projection cids the host received after scheduling; non-material edits only (N11) |
| sellerId | actorId — did:key of the seller; signs terms and auction_cancel |
| hostRelayId | string — identifier of the selected host relay; required |
| hostKeyId | string — Ed25519 key of the host used to verify every host statement of this auction |
| currency | string — registered ISO 4217 code (F09.S03.M01) |
| startPrice | Money — CTR-MNY-001; > 0; ≤ 1 000 000 000 000 minor units |
| reserveCommitment? | string — sha256- hash over reserve minor units and reserveSalt |
| reservePrice? | Money — P3 in the seller vault; P2 to the host only, inside an envelope E2E-encrypted to hostKeyId; ≥ startPrice |
| reserveSalt? | string — 16 random bytes base64url; same classification and transport as reservePrice |
| incrementTable | Tier[] — 1..8 tiers {fromMinor, incrementMinor}; default-v1 when omitted; strictly increasing fromMinor, non-decreasing increments, each increment ≥ 1 minor unit and ≤ 20 percent of fromMinor (first tier ≤ startPrice) |
| softCloseRulesVersion | string — softclose-v1 in v1; signed in the terms and echoed in host_acceptance; unknown versions are refused |
| startsAt | timestamp — host clock, RFC 3339 UTC, between now and now plus 30 days |
| scheduledEndsAt | timestamp — startsAt plus 1 h..14 d |
| acceptBy | timestamp — min(terms signing time + 24 h, startsAt + 5 min); signed in the terms; the host refuses acceptance after it by host clock |
| currentEndsAt | timestamp — scheduledEndsAt plus extensions, at most scheduledEndsAt plus 60 minutes |
| extensionCount | int — 0..30, owned by F04.S02.M02 |
| currentPrice? | Money — projection of the leading amount; absent before the first bid |
| bidCount | int — projection >= 0 |
| reserveMet | boolean — projection; true when currentPrice >= reservePrice or no reserve |
| termsCid | string — sha256- cid of the signed auction terms |
| hostAcceptanceCid? | string — cid of the host_acceptance statement |
| openedCid? | string — cid of the host-signed auction_opened statement |
| hostCancelCid? | string — cid of the host-signed host_cancel statement |
| pushOptIn | boolean — seller allows content-free host pushes; true only when privacy.consent.check(notify_push) for the host is granted |
| status | enum — draft \| proposed \| cancel_pending \| scheduled \| open \| closed \| cancelled \| host_silent \| needs_host_check |
| cancelReason? | enum — seller \| host_unreachable \| host_refused \| host_policy \| listing_unavailable \| accept_window_passed |
| syncState | map — {host: prepared \| transport_acknowledged \| peer_accepted} |
| revision | int — CTR-ID-001 ID-4 |
| createdAt | timestamp — RFC 3339 UTC |

**Invariants**
- status scheduled, open or closed implies listingId, listingCid, hostRelayId, hostKeyId, termsCid and hostAcceptanceCid are set and verified, and the acceptance host time is at or before acceptBy.
- reservePrice and reserveSalt never appear in any event payload, public projection, log or export other than the seller's own; on the host they exist only decrypted inside the host process for this auction.
- currentEndsAt is at least scheduledEndsAt and at most scheduledEndsAt plus 60 minutes.
- A cancelled auction has bidCount 0 unless cancelReason is host_policy.
- At most one Auction per listing is in proposed, cancel_pending, scheduled, open or needs_host_check; host_silent, closed and cancelled release the listing.

### Storage DDL

```sql
CREATE TABLE auctions_auction (
  id TEXT PRIMARY KEY, tenant_id TEXT NOT NULL, listing_id TEXT, seller_id TEXT NOT NULL, host_relay_id TEXT NOT NULL,
  currency TEXT NOT NULL, start_price_minor TEXT NOT NULL, starts_at TEXT NOT NULL, accept_by TEXT, scheduled_ends_at TEXT NOT NULL,
  current_ends_at TEXT NOT NULL, status TEXT NOT NULL, revision INTEGER NOT NULL, data TEXT NOT NULL);
CREATE INDEX auctions_auction_due ON auctions_auction(status, starts_at, current_ends_at);
CREATE UNIQUE INDEX auctions_auction_listing ON auctions_auction(tenant_id, listing_id)
  WHERE listing_id IS NOT NULL AND status IN ('proposed','cancel_pending','scheduled','open','needs_host_check');
```
