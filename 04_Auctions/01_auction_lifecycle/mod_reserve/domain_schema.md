## Requirements

- **PS-035-01.R01** An Auction stores listing, seller, host relay identity and key, currency, start price, reserve commitment, increment table, schedule, extension counters, price projection and status, with revision per CTR-ID-001.
- **PS-035-01.R02** The reserve value is P3, stored only in the seller vault and, encrypted to the host key, on the host relay; public terms and events carry only the salted hash commitment and a reserveMet flag.
- **PS-035-01.R03** Money is integer minor units per CTR-MNY-001; increments are computed from a tiered table in major-unit templates converted with ceiling to the currency exponent.

## Specification

### Auction

Schema `classrup.auctions.auction/v1` · storage **relay+device** · privacy **P3** · retention **RET-EVIDENCE**

| Field | Type and constraints |
|---|---|
| id | uuidv7 — primary key, generated by the seller vault |
| tenantId | uuidv7 — host relay tenant scope |
| listingId | uuidv7 — ref F01.S01.M01 Listing of subtype auction; published |
| sellerId | actorId — did:key of the seller; signs terms |
| hostRelayId | string — identifier of the selected host relay; required |
| hostKeyId | string — Ed25519 key of the host used to verify receipts and results |
| currency | string — registered ISO 4217 code (F09.S03.M01) |
| startPrice | Money — CTR-MNY-001; > 0; ≤ 1 000 000 000 000 minor units |
| reserveCommitment? | string — sha256- hash over reserve minor units and a 16-byte salt |
| reservePrice? | Money — P3; seller vault and host only; ≥ startPrice |
| incrementTable | Tier[] — 1..8 tiers {fromMinor, incrementMinor}; default-v1 when omitted; strictly increasing fromMinor, non-decreasing increments, each increment ≥ 1 minor unit and ≤ 20 percent of fromMinor (first tier ≤ startPrice) |
| startsAt | timestamp — host clock, RFC 3339 UTC, between now and now plus 30 days |
| scheduledEndsAt | timestamp — startsAt plus 1 h..14 d |
| currentEndsAt | timestamp — scheduledEndsAt plus extensions, at most scheduledEndsAt plus 60 minutes |
| extensionCount | int — 0..30, owned by F04.S02.M02 |
| currentPrice? | Money — projection of the leading amount; absent before the first bid |
| bidCount | int — projection >= 0 |
| reserveMet | boolean — projection; true when currentPrice >= reservePrice or no reserve |
| termsCid | string — sha256- cid of the signed auction terms |
| hostAcceptanceCid? | string — cid of the host_acceptance statement |
| status | enum — draft \| proposed \| scheduled \| open \| closed \| cancelled |
| cancelReason? | enum — seller \| host_unreachable \| host_refused \| host_policy \| listing_unavailable |
| syncState | map — {host: prepared \| transport_acknowledged \| peer_accepted} |
| revision | int — CTR-ID-001 ID-4 |
| createdAt | timestamp — RFC 3339 UTC |

**Invariants**
- status scheduled or later implies hostRelayId, hostKeyId, termsCid and hostAcceptanceCid are set and verified.
- reservePrice never appears in any event payload, public projection, log or export other than the seller's own.
- currentEndsAt is at least scheduledEndsAt and at most scheduledEndsAt plus 60 minutes.
- A cancelled auction has bidCount 0 unless cancelReason is host_policy or listing_unavailable.

### Storage DDL

```sql
CREATE TABLE auctions_auction (
  id TEXT PRIMARY KEY, tenant_id TEXT NOT NULL, listing_id TEXT NOT NULL, seller_id TEXT NOT NULL, host_relay_id TEXT NOT NULL,
  currency TEXT NOT NULL, start_price_minor TEXT NOT NULL, starts_at TEXT NOT NULL, current_ends_at TEXT NOT NULL,
  status TEXT NOT NULL, revision INTEGER NOT NULL, data TEXT NOT NULL);
CREATE INDEX auctions_auction_due ON auctions_auction(status, starts_at, current_ends_at);
CREATE UNIQUE INDEX auctions_auction_listing ON auctions_auction(tenant_id, listing_id) WHERE status IN ('proposed','scheduled','open');
```
