## Requirements

- **PS-045-01.R01** A SearchDocument stores only P0 fields from a signature-verified public projection, a location cell snapped to geohash precision 5 or coarser, and provenance (author DID, projection cid, origin, first-seen time).
- **PS-045-01.R02** The FTS5 table indexes title and body only; every other attribute is a typed column used by filters and ranking.
- **PS-045-01.R03** Removed documents lose title and body immediately and are purged 30 days after removal; the row until then only guarantees idempotent replay and tombstone handling.

### SearchDocument

Schema `classrup.discovery.search_document/v1` · storage **relay+device** · privacy **P0** · retention **RET-STANDARD**

| Field | Type and constraints |
|---|---|
| id | uuidv7 — primary key, generated by the vault or relay that indexes it |
| tenantId | uuidv7 — tenant scope (single fixed tenant in a vault) |
| sourceKind | enum — listing \| offering \| auction \| rental |
| sourceId | uuidv7 — id of the source aggregate; unique with tenantId and sourceKind |
| sourceRevision | int — highest source revision applied; older events are ignored |

| origin | enum — own \| fetched \| imported \| relay_published |
| listingKind | enum — sell \| wanted \| giveaway \| service \| rental \| auction |
| title? | string — 1..120 code points after NFC and control-character stripping; null when removed |
| body? | string — 0..2000 code points, plain text; null when removed |
| categoryId | uuidv7 — category from governance catalog |
| priceMinor? | int — 0..1 000 000 000 000, minor units per CTR-MNY-001 |
| currency? | string — registered currency code, required when priceMinor is set |
| condition? | enum — new \| like_new \| good \| fair \| for_parts |
| barterAcceptable | boolean — author accepts barter proposals |
| geoCell5 | string — geohash of exactly 5 characters (L2) or empty string when the author shows no location |
| claimedPublishedAt | timestamp — author's claim, never trusted for ordering |
| firstSeenAt | timestamp — local clock when this vault or relay first indexed the document |
| authorFirstSeenAt | timestamp — local clock when this index first saw any document by authorDid |
| expiresAt | timestamp — claimed source expiry; document removed at or after min(expiresAt, firstSeenAt + 90 d) |
| endsAt? | timestamp — claimed auction end |
| promotedUntil? | timestamp — relay-local paid promotion end; always null in a vault index |
| status | enum — active \| removed \| purged |
| removedReason? | enum — unpublished \| expired \| archived \| sold_out \| tombstoned \| hosting_policy \| local_hidden \| deleted \| auction_closed \| withdrawn \| evicted |
| removedAt? | timestamp — set when status becomes removed |
| revision | int — CTR-ID-001 ID-4, increments on every applied change |
| createdAt | timestamp — RFC 3339 UTC |
| updatedAt | timestamp — RFC 3339 UTC |

**Invariants**
- geoCell5 is empty or a valid geohash of length exactly 5; a longer value is never stored.
- status active implies the stored projection signature verified against authorDid and title is non-null.
- status removed or purged implies title and body are null and no discovery_fts row exists for the document.
- At most one document exists per (tenantId, sourceKind, sourceId, authorDid).

### Storage DDL

```sql
CREATE TABLE discovery_doc (
  rid INTEGER PRIMARY KEY, id TEXT NOT NULL UNIQUE, tenant_id TEXT NOT NULL, source_kind TEXT NOT NULL,
  source_id TEXT NOT NULL, source_revision INTEGER NOT NULL, author_did TEXT NOT NULL, projection_cid TEXT NOT NULL,
  origin TEXT NOT NULL, listing_kind TEXT NOT NULL, title TEXT, body TEXT, category_id TEXT NOT NULL,
  price_minor INTEGER, currency TEXT, condition TEXT, barter INTEGER NOT NULL DEFAULT 0,
  geo_cell5 TEXT NOT NULL DEFAULT '' CHECK (length(geo_cell5) IN (0,5)), claimed_published_at TEXT NOT NULL,
  first_seen_at TEXT NOT NULL, author_first_seen_at TEXT NOT NULL, expires_at TEXT NOT NULL, ends_at TEXT,
  promoted_until TEXT, status TEXT NOT NULL, removed_reason TEXT, removed_at TEXT, revision INTEGER NOT NULL, data TEXT NOT NULL);
CREATE UNIQUE INDEX discovery_doc_source ON discovery_doc(tenant_id, source_kind, source_id, author_did);
CREATE INDEX discovery_doc_cell ON discovery_doc(tenant_id, status, geo_cell5, first_seen_at);
CREATE INDEX discovery_doc_author ON discovery_doc(tenant_id, author_did, status);
CREATE VIRTUAL TABLE discovery_fts USING fts5(title, body, content='discovery_doc', content_rowid='rid',
  tokenize='unicode61 remove_diacritics 2', prefix='2 3');
```
