## Contract

- PS-116-08.R01: Proposed reference fixture: declared midrange device/browser, 10000 owner queue entries, owner paged index available, page100, 100 hint/status changes and 10000-event burst. Target p95 local getView <=100ms, stable hint/status visible <=1000ms including 500ms coalescing, per-render main-thread task <=50ms; paginate/yield rather than copy full queue. No internet availability SLO or peer-latency target. No adapter configured triggers zero network attempts.
- PS-116-08.R02: Optional local diagnostics off by default, capped core ring1000 entries/7days. Allowlisted fields `{local_request_id,code,phase:hint|query|reconcile|schedule,duration_bucket,count_bucket}` only; no vault/principal/object/destination IDs, endpoint URLs, raw adapter error text, precise timestamps per item or private payload. Diagnostic export needs explicit preview; metrics never upload by default. Queue age derives client clock and shows uncertain if anomalous, not proof of delivery latency.
- PS-116-08.R03: In-app status shows storage unavailable/unknown outcome, paused reconciliation and dead-letter count only when authorized; browser closed means no alert guarantee. Runbook: stop new dispatch -> requery owner receipt/status -> inspect typed storage/protocol/adapter code -> offer bounded retry/export through owner. Never “fix offline” by clearing vault, bypassing encryption, enabling global service, dropping events or resetting attempts. Visible local draft remains usable while remote adapter fails.

TEST-PS-116-08 record fixture/device and percentiles, event-flood task durations, forced slow status port, no-adapter network trace and diagnostic canary scan. All budgets proposed/unmeasured; no executed benchmark or SLO claim.
