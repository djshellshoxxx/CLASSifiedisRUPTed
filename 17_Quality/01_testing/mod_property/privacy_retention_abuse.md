## Requirements

- **PS-136-07.R01** Generated data is synthetic; arbitraries produce coordinates only after geohash coarsening to L2 (precision 5) when asserting privacy invariants.
- **PS-136-07.R02** Reports contain generated values only for failures, retained 30 days as CI artifacts, and never contain real data.
- **PS-136-07.R03** Seeds are not secret; they are printed in logs and PR comments.

## Specification

**Data classification**
- Generated values: synthetic P0.
- Reports: seeds, paths and shrunk counterexamples.

**Retention**
- Reports 30 days as CI artifacts; regression JSON files are kept in git indefinitely.

**Threats and controls**

| ID | Threat | Control |
|---|---|---|
| T01 | Counterexample contains real data pasted by a developer into a regression | regression files are generated by the tool only; lint rejects hand-edited files without the generator signature |
| T02 | Properties silently weakened by lowering numRuns | numRuns floor enforced by the runner (QUALITY_PROP_RUNS_TOO_LOW); the config file is code-owned |
| T03 | Nightly job used to exfiltrate secrets | nightly workflow has permissions contents: read and no secrets; fork pull requests never run it |

**Abuse controls**
- A property that always passes (no assertion) is caught by a self-test requiring at least one assertion call per property.
- Seeds are never reused to hide a failure: reruns use the printed seed only for replay.
