## Requirements

- **PS-147-01.R01** A PolicyProposal records publisher, target type and references, structured proposed change (at most 16 KiB), summary, comment period, status, decision and changelog entry.
- **PS-147-01.R02** Proposals, decisions and comments are public to the publisher's community (P1 comments, P0 proposals and decisions) and are signed statements verified by every receiving vault.
- **PS-147-01.R03** Decisions bind exact target references and expire for use after 30 days; they are evidence retained under RET-EVIDENCE.

### PolicyProposal

Schema `classrup.governance.policy_proposal/v1` · storage **relay+device** · privacy **P0** · retention **RET-EVIDENCE**

| Field | Type and constraints |
|---|---|
| id | uuidv7 — primary key |
| tenantId | uuidv7 — fixed local-vault tenant (ID-6) |
| publisherId | did:key — proposer and origin; canonical owner |
| title | string — 3..120 code points |
| summary | string — 10..2000 code points, plain text |
| targetType | enum — jurisdiction_profile \| prohibited_rule \| category \| platform_policy \| other |
| targetRefs | string[] — 1..20 ids or keys of the targets |
| proposedChange | object — structured change, <= 16 KiB JCS |
| changelogEntry | string — 10..1000 code points, public |
| commentPeriodHours | int — 72..720, default 336; 24..72 only when expedited |
| expedited | boolean — default false; requires expeditedReason and coSignerId |
| expeditedReason? | string — 10..500 code points |
| coSignerId? | did:key — second operator key for expedited proposals, differs from publisherId |
| status | enum — draft \| open_for_comment \| decision_pending \| approved \| rejected \| withdrawn |
| openedAt? | timestamp — publisher clock, a claim |
| commentEndsAt? | timestamp — openedAt + commentPeriodHours |
| commentCount | int — derived, visible comments |
| outcome? | enum — approved \| rejected |
| rationale? | string — 10..2000 code points |
| deciderId? | did:key — signer of the decision, differs from publisherId |
| decidedAt? | timestamp — publisher clock, a claim |
| validUntil? | timestamp — decidedAt + 30 d |
| statementCid? | string — sha256- of the latest signed statement |
| revision | int — CTR-ID-001 ID-4 |
| createdAt | timestamp — RFC 3339 UTC |
| updatedAt | timestamp — RFC 3339 UTC |

**Invariants**
- deciderId differs from publisherId for approved and rejected outcomes.
- status approved or rejected implies rationale, deciderId, decidedAt and a verified decision statement exist.
- commentPeriodHours >= 72 unless expedited with reason and a co-signer; commentEndsAt = openedAt + commentPeriodHours.

| authorId | did:key — signer, pseudonymous |
| body | string — 1..2000 code points, plain text |

**Invariants**
- At most 5 visible comments per (proposalId, authorId).
- Comments are accepted only while the proposal is open_for_comment according to the relay clock.
- A hidden comment keeps its signed statement for audit but is not displayed.
