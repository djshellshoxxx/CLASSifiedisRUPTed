## Continuation and verification

Keep the historical tracker and five source audits intact. A proposed closure
should identify the exact source candidate, all affected workflows, an approved
contract/owner where required, negative acceptance evidence and remaining limits.
Changes spanning multiple controls need a cross-domain reviewer; a related helper
or a single happy-path test is insufficient.

composition, owning-domain consent/backup/quarantine adapters, canonical device
and recipient-key lifecycle, and evidence-aware retention. Private messaging,
services/rentals and auctions must not be exposed through placeholder transport,
payment verification or time authority. Manual/device/operational evidence is a
separate task from adding source code.
