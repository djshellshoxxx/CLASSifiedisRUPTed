Deviations from the specification:

- formatMoney, formatMoneyParts and formatApprox return Result<...>, not bare strings. The spec says invalid input yields an explicit error and no string (T04).
- formatApprox uses decimal style plus the code ("42.10 EUR") as in the spec example.
- FSI/PDI isolation is added only for RTL locales or when bidi controls were stripped, so the en examples match the spec byte for byte. In en, the BTC code is not wrapped. T06 asserts isolation in ar-XB.
- Input over 40 characters returns I18N_MONEY_TOO_LARGE; the spec names no code for this.

- A missing quote source renders the "quote details unavailable" text. A missing or malformed asOf with a source present, or an invalid time zone, is I18N_QUOTE_LABEL_INVALID.
- money.currency must equal spec.code, otherwise I18N_MONEY_INVALID.
- No built-in exponent table: the spec says the exponent comes from the registry, so the fallback table was not added.
