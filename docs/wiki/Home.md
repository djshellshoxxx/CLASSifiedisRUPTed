# CLASSifiedisRUPTed (ClassRup)

**Navigation:** [User Guide](User-Guide.md) · [Developer Guide](Developer-Guide.md)

ClassRup is a proposed local-first, privacy-aware PWA combining **LocalBazaar** listings and **LocalMutiny** consent-based barter. The product is **not released**. The repository default branch remains planning-only; the actual local alpha is under **draft [PR #10](https://github.com/djshellshoxxx/CLASSifiedisRUPTed/pull/10)** stacked on draft [PR #8](https://github.com/djshellshoxxx/CLASSifiedisRUPTed/pull/8). Do not mistake the draft alpha for a merged or deployed product.

## Choose your path

- **[User Guide](User-Guide.md)** — availability, setup, creating a local vault, exchanging signed evidence files, barter flows, recovery, limitations, troubleshooting and FAQs.
- **[Developer Guide](Developer-Guide.md)** — architecture, installation, commands, tests/CI, contracts, security boundaries, contributing and release gates.
