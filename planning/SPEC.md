# planning — planning documents

## Purpose and behavior
Own planning workflow guidance and staged execution prompts, not product runtime behavior.

## User stories and scope
Architects can navigate and execute documented stages. No application implementation in this folder.

## Public interfaces and relationships
Markdown navigation; upstream PROJECT_SPEC.md; downstream staged planning prompts and INDEX.md.

## Dependencies and data ownership
Depends on project governance. Owns only planning instructions, not product or user data.

## Risks and completion
Prevent premature implementation and conflicting phase gates. Complete when documents are linked, versioned and internally consistent.
