# ADR-0001 — PWA trust boundaries

**Status:** ACCEPTED. **Date:** 2026-11-04.

## Decision
The static PWA host serves untrusted client code. All authorization, validation, durable persistence, rate limiting and event ordering are enforced by an independently deployed relay (`apps/relay`). Client checks are UX only. External wallets, chains, payment providers and physical exchanges are outside the trust boundary; the platform records claims and independently verified observations only.

## Consequences and notes
GitHub Pages or any static host may serve `apps/pwa` build output; the relay needs a server (container or VM). Documented in `docs/DEPLOYMENT.md`.
