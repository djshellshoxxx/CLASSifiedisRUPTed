# ADR-0002 — Implementation architecture: modular monorepo with a command bus

**Status:** ACCEPTED. **Date:** 2026-11-04.

## Decision
TypeScript (erasable syntax only, runs natively on Node ≥ 22.18 via type stripping) in a pnpm workspace. One package per feature (`packages/<featureSlug>`), plus `packages/kernel` for canonical contracts. Each module lives at `packages/<slug>/src/<subfeature>/<module>/` and exposes schemas, pure rules, a state machine and command/query handlers through its `index.ts`. Handlers depend only on ports (`Repo`, `Clock`, `Ids`, `EventSink`, external adapters); `apps/relay` is the single composition root that wires ports to SQLite (`node:sqlite`) and HTTP. Cross-cutting concerns (validation, capability check, feature flag, idempotency, rate limit, audit, transactional outbox) are implemented once in the kernel command bus, not per module. Commands are RPC-style `POST /api/v1/cmd/<command.name>`; queries `POST /api/v1/query/<query.name>`.

## Consequences and notes
Dependency direction is enforced by a test (`tools/deps`): kernel ← security, privacy, platform, i18n, governance ← identity, commerce, discovery, comms, notify, moderation, federation ← bazaar, mutiny, services, auctions, rentals ← apps. Feature packages never import each other sideways except through the listed layers; cross-feature data flows through events or ports.
