# ADR-0004 — D01 Federation: versioned signed envelopes, explicit opt-in

**Status:** ACCEPTED. **Date:** 2026-11-04.

## Decision
MVP federation uses CTR-FED-001 envelopes: Ed25519 signatures over JCS, did:key authors, relay-to-relay signed HTTPS batches between allowlisted peers. Only P0 records explicitly opted in by their owner federate. ActivityPub/AT Protocol bridges are FUTURE (F11.S03.M03 migration documents mapping) because neither provides marketplace-specific consent, tombstone and geoprivacy semantics without extensions.

## Consequences and notes
Federation feature flag off by default.
