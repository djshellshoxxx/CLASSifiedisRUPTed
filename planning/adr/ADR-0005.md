# ADR-0005 — D02 Cycle optimizer: bounded deterministic cycle enumeration

**Status:** ACCEPTED. **Date:** 2026-11-04.

## Decision
Build a directed compatibility graph: edge A→B when an item A offers satisfies an active want of B (category, condition, value window, distance bucket, both not blocked). Enumerate elementary cycles of length 2..Lmax (default Lmax = 5, tenant max 8) with a Johnson-style DFS restricted to start-node minimality (each cycle found once), with deterministic node order (UUIDv7 ascending) and hard budgets (≤ 100 000 expanded nodes, ≤ 250 ms). Score = (participants, −relative value imbalance, −max distance bucket, oldest-want age). Select disjoint cycles greedily by score. Maximum-weight cycle packing is NP-hard for cycle cap ≥ 3 (Abraham, Blum, Sandholm 2007), so greedy with budgets is a deliberate trade-off; results are suggestions requiring all-party consent.

## Consequences and notes
Exact ILP solver is FUTURE behind the same port.
