# ADR-0007 — D04 Partial barter execution

**Status:** ACCEPTED. **Date:** 2026-11-04.

## Decision
No atomic real-world guarantee. Cycle execution is a saga: lock (lease) → all-party consent on an immutable proposal revision → per-leg handover attestations by giver and receiver → completed when all legs attested by receivers. Dropout before any handover cancels the cycle and releases locks; dropout after partial handover moves the cycle to `partially_executed` with recovery options (return item, compensation leg, dispute). No silent rerouting.
