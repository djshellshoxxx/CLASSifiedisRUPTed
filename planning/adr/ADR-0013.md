# ADR-0013 — D10 Authentication and portability

**Status:** ACCEPTED. **Date:** 2026-11-04.

## Decision
User-controlled Ed25519 device keys generated in the browser with WebCrypto-backed randomness via @noble/curves; private key stored in IndexedDB encrypted (XChaCha20-Poly1305) with a key derived by scrypt (N=2^17, r=8, p=1; OWASP minimum) from a user passphrase — scrypt chosen over argon2id because the @noble/hashes argon2 implementation is unaudited or held as non-extractable WebCrypto key where supported. Account = account ID + set of device public keys; adding a device requires a signed link from an existing device. Recovery: one-time recovery kit (24-word-equivalent random secret, shown once) that encrypts an account recovery key; relays store only the encrypted blob and a verifier. Key rotation emits `identity.device_key.rotated` events. did:key derived from the account signing key for federation.

## Consequences and notes
Passkeys/WebAuthn as second factor is FUTURE.
