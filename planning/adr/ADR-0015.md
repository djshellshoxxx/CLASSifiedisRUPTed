# ADR-0015 — Specifications as data

**Status:** ACCEPTED. **Date:** 2026-11-04.

## Decision
Each module is specified once in `module.spec.yaml` (schema in `planning/SPEC_FORMAT.md`). `tools/specgen` validates it (required sections, stable IDs, cross-module references for events/capabilities/errors/dependencies, no TBD/TODO) and renders the ten process documents, module SPEC.md section, PROCESS_CHECKLIST.md, registries and completeness report. Implementation tests reference requirement IDs for traceability.

## Consequences and notes
Hand-editing generated process documents is not allowed; edit the YAML and re-render.
